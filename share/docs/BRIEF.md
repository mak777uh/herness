# BRIEF — краткая справка для классов без инструментов

Читается `core/live.py` в режиме без инструментов. Одна страница, не больше: это ориентация,
а не документация.

herness — инструмент, который проверяет утверждения и показывает собственную погрешность.
Имя составлено из **her + harness** (впрягать в работу под конкретного человека), а не из
английского harness напрямую.

В репозитории: `CLAIMS.md` — реестр утверждений с командами, `docs/CRITERIA.md` — критерии,
`lab/failures` — разобранные отказы, `runs` — журналы прогонов.

Границы: модель без инструментов не видит файлов и не может проверить ничего в среде. Её ответ —
это её вывод, а не факт о проекте.
