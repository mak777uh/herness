# PUBLICATION-POLICY — что публично, а что нет

Дата: 29.10.2026. Основание: A12 (публичный репозиторий) и решение владельца разделить зоны.

Принцип: **не публиковать лишнего** — это гигиена, а не маскировка. Всё, что опубликовано,
должно быть правдой без умолчаний, которые меняют смысл. Всё, что не нужно публике, не
публикуется вовсе.

## Три зоны

| зона | что там | можно ли публиковать |
|---|---|---|
| **A. публичная** | ядро, контракты, журнал, тесты, архитектурные ADR без операционных деталей, принципы, роадмап | да |
| **B. внутренняя** | конфиги хоста, адреса, имена узлов, расписания, бюджеты прогонов, ответы владельца | нет, только по решению владельца |
| **C. приватная** | ключи, bootstrap-списки, операционные детали маршрутов, обвязка узлов, всё, что описывает «как именно» | нет, никогда в публичном |

Правило по умолчанию: **сомневаешься — зона B**. Перевод из B в A — отдельное решение с записью.

## Текущая раскладка

| файл | зона | почему |
|---|---|---|
| `bin/hs.py`, `core/`, `tests/` | A | инструмент и контракты, без операционных деталей |
| `docs/PRINCIPLES.md`, `docs/ROADMAP.md` | A | правила и порядок работ |
| `docs/QUESTIONS.md` (раздел B) | A | вопросы про внешний мир |
| `docs/QUESTIONS.md` (раздел A), `docs/ANSWERS.md` | B | личные решения владельца |
| `docs/ADR-0001…0006` | A | архитектурные решения |
| `docs/ADR-0007`, `ADR-0008`, `ADR-0013` | A | переписаны в техническом регистре: механизмы и границы, без формулировок о назначении |
| `docs/prompts/P1…P5` | A | внешние вопросы без внутреннего контекста |
| `docs/prompts/P6`, `P7`, `P8` | A | технические вопросы о свойствах каналов; без операционных деталей |
| `research/answers/**` | B | сырые ответы моделей, могут содержать следы контекста |
| `refs-cache/**` | B | копии чужих документов |
| `home/`, `runs/` | C | сессии, артефакты, пути, ключи |

## Чек-лист перед публикацией

1. `python bin/hs.py gates` — зелёный (секреты, утверждения, ссылки).
2. Поиск по публикуемым файлам: IP-адреса, домашние пути, имена пользователей, названия узлов.
3. Поиск: `bootstrap`, `onion`, `proxy`, `ключ`, `token` — каждое вхождение объяснено
   или файл не публикуется.
4. Ни одного обещания, которого нет в `NOT-CLAIMED.md`.
5. Ни одной фразы, которая станет ложной при первом же вопросе «а покажите».

## Чего этот документ не делает

Он не превращает неправду в правду. Если механизм делает X, документ не должен утверждать, что
он делает не X. Он лишь решает, **что** из правды попадает в публичный доступ.
