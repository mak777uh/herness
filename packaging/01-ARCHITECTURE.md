## Почему именно так

### Ядро своё, а не готовое

**Причина:** готовый дистрибутив несёт тысячи пакетов, каждый — поверхность атаки. Своё ядро на
`tinyconfig` — 3,1 МБ вместо 14 МБ, без модулей, без поддержки того, что не нужно.

**Цена:** надо собирать самому, обновлять вручную, отлаживать сложнее.

### Нет shell и coreutils

**Причина:** если в комнате есть `sh`, `curl`, `python`, то агент может делать что угодно этими
инструментами, и наша политика ничего не значит.

**Цена:** всё, что нужно, приходится делать своими инструментами.

### Инструменты — функции, а не процессы

**Причина:** процесс — это ещё одна поверхность (аргументы, окружение, сигналы). Функция в
адресном пространстве `init` — одна точка входа.

**Цена:** инструмент не может упасть отдельно; ошибка в нём роняет `init`.

### Журнал append-only с CRC

**Причина:** если журнал можно переписать, то и свидетельство ничего не стоит.

**Цена:** журнал растёт; обрыв на записи оставляет хвост, который **не чинится** — это
объявленное поведение, а не дефект.

## Цикл работы агента

```
модель → строка протокола → харнесс → инструмент → результат → модель
```

**Протокол — одна строка:**

| команда | что значит |
|---|---|
| `TOOL <имя> <аргумент>` | вызвать инструмент |
| `DONE <итог>` | закончить с результатом |
| `BLOCKED <почему>` | застрял, нужна помощь |
| `NO-WORK` | делать нечего |

**Почему одна строка, а не JSON:** разбор строки — 20 строк кода, разбор JSON — библиотека.
Каждая библиотека в комнате — поверхность атаки.

## Посредник

**Решение о доступе принимает политика, а не код инструмента.**

```rust
// Инструмент спрашивает политику, а не решает сам
let resource = resource_of(&path, &root);   // file:/mnt/...
if !policy_allows("read", "read", &resource) {
    return Err(format!("политика не разрешает чтение: {resource}"));
}
```

**Политика — данные:** 17 правил в `lab/tools/policy.json`, и та же политика в константе
`POLICY` в коде. Расхождение ловит гейт `policy_sync.py`.

**Правило приоритета:** запрет сильнее разрешения. Что не разрешено — запрещено.

## Приёмка

**Критерий объявлен ДО прогона** и лежит на хосте. В комнату он не попадает, поэтому агент не
может его прочитать и подогнать ответ.

**Приёмка проверяет вынесенный журнал**, а не ответ агента. Ответ — это утверждение; журнал —
это свидетельство.

## Что делает подход непохожим на обычный сервис

| обычный сервис | здесь |
|---|---|
| доверяет своему коду | **не доверяет: код проверяется гейтами** |
| «мы проверили безопасность» | **«вот что доказано, вот что измерено, вот чего не утверждаем»** |
| критерий приёмки в голове разработчика | **критерий в файле, объявлен до прогона** |
| ошибка = исключение | **ошибка = код отказа из закрытого словаря** |
