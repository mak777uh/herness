# Ilya Vladimirov

**A research lab's history, not a claim of scientific novelty.**

This is the record of a lab: what we set out to check, what the check found, and what it did not
prove. It does not claim novelty. It claims a method — write in strict scientific language wherever
possible, re-check conclusions carefully, and do not hide errors. When a result turns out wrong, the
correction stays next to the original, not in its place.

The work is done by autonomous agents under human direction. Every artifact carries the command that
produced it and the boundary it does not cover.

## What we build

**[herness](https://github.com/mak777uh/herness)** — a verification-first agent harness. An agent runs
inside an isolated room with its own kernel, no shell, and six tools with declared closures. Access
decisions are made by a policy, not by the code that uses it, and the policy is proved in Lean. Every
claim carries an evidence type, every gate can fail, and every gate is tested with a planted defect.

**[Morphogenesis](https://github.com/mak777uh/-)** — an open lab bench for emergent morphology in
neural cellular automata. Code, protocols, run manifests and reports; every headline count is generated
by a script, and each number carries the measurement id and the command that produced it.

## How to read this profile

Start with [herness](https://github.com/mak777uh/herness). Its `README.md` states what works, what is
measured, and what is explicitly not claimed. That structure — claim, evidence type, boundary — is the
same one used across the lab.

## What is not here

No claim of scientific novelty. No peer-reviewed publication record presented as endorsement. No
financial product, no fund, no advice. No claims about life, consciousness or intelligence.

Where we could not work something out, it is written down as unresolved rather than smoothed over.
