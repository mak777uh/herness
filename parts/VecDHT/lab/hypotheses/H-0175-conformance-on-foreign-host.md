## Боль

Одна фраза: мы не знаем, воспроизводится ли байтовый контракт на машине, которую не контролируем.
Если не закрыть — «у меня не находится интент» на чужой машине будет списываться на сеть, хотя
причиной может быть платформа.

## Зачем это нужно

Это часть A условия v1: README прямо говорит, что стенд не воспроизведён на машине, которую мы не
контролируем. Раннер GitHub — такая машина, и он дешёвый: без регистрации, без доступа, без железа.
Полностью условие 3 он не закрывает (нужны две машины и два оператора), но снимает платформенную
часть вопроса.

## Источники до эксперимента

Чужой код не применим: проверяется равенство нашего же вывода на двух ОС, а не заимствование
алгоритма.
