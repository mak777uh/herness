# inbox — заметки аудита

```
inbox/
  harness/        заметки о самом харнессе (общая папка)
  <agent-id>/     заметки конкретному агенту
```

Правила (ADR-0017):

1. Заметка — файл, а не сообщение в чате. Append-only: исправление — новая заметка со ссылкой.
2. Без `repro` — не находка, а мнение. Мнения считаются отдельно и в совет не идут.
3. `severity` — про последствия, а не про раздражение.
4. `would_change` обязателен по смыслу: автор говорит, что его переубедит.

Формат:

```
from: agent-a
to: harness
about: ADR-0017
severity: medium
repro: python bin/hs.py gates   → 0 проблем при посаженной заметке без repro
finding: гейт не отбивает заметки без воспроизводящего случая
would_change: если gate_audit начнёт падать на посаженной заметке
```

Проверка: `python bin/hs.py audit`.
