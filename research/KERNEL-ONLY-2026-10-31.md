# Путь «только ядро»: проверено (31.10.2026)

Вопрос: можно ли строить харнесс, взяв от Linux **только ядро**, без дистрибутива как зависимости?

Ответ: **да, и это уже проверено на практике.**

## Что значит «только ядро» в нашем случае

Харнессу нужны не пакеты Ubuntu, а **системные вызовы**: файлы, процессы, хеши, таймеры, песочница.
Дистрибутив приносит только `bash`, `coreutils` и менеджер пакетов — для ядра харнесса это не нужно.

## Замеры

| проверка | результат |
|---|---|
| сборка статического бинарника | `x86_64-unknown-linux-musl`, **690 232 байта** |
| динамические зависимости | **statically linked** (`ldd` → «statically linked») |
| запуск с **пустым окружением** (`env -i`) | работает, печать посчитана |
| совпадение с Python | **хеш совпал байт в байт**: `643fe261918f28e67762c983f1fd3f3642bdd42ddd7f57f9f6f51090d73cab67` |
| Landlock без root (`uid=1000`) | **доступен, ABI 3** |
| Landlock под root | тоже ABI 3 |
| `unshare` без root | **Operation not permitted** |
| `unshare` под root | работает |
| `sudo` без пароля | нет |

## Что это даёт для решения

1. **Зависимость от дистрибутива — ноль.** Бинарник не тянет ни libc, ни пакетов; он говорит с ядром.
   Значит целевая платформа — **любое ядро**, а не «Ubuntu» и не «NixOS».
2. **Песочница файловой системы доступна без root** — Landlock ABI 3 это умеет. Это ровно то, что нужно
   для гейта прав: ограничить агенту запись, не давая ему привилегий.
3. **Сеть через Landlock недоступна.** Ограничения сети появились в ABI 4 (ядро ≥ 6.7), а WSL даёт
   ABI 3. Пока сетевую песочницу закрываем не ядром, а тем, что у нас нет сетевых инструментов у агента.
4. **Namespaces — только с привилегиями.** `unshare` без root запрещён; значит изоляция через
   namespaces — это либо root-помощник, либо профиль, либо будущее ядро, где разрешено.

## Следствие для D2 (ОС на железе)

**Выбор ОС перестаёт быть выбором** в части ядра: наш бинарник одинаково пойдёт на Ubuntu, NixOS, Alpine
или голом ядре с initramfs. Остаётся вопрос удобства эксплуатации:

- **NixOS** даёт воспроизводимую сборку (C8) — полезно, но не обязательно: наш `Cargo.lock` уже даёт
  воспроизводимость зависимостей.
- **Ubuntu** даёт простую установку и знакомые инструменты.
- **Голое ядро + статический бинарник** технически возможно, но это уже D4–D5 по карте глубин и цена
  непропорциональна выигрышу.

**Минимальный контракт ядра** (записать в ADR): Linux с **Landlock ABI ≥ 3**; для сетевых ограничений —
ABI ≥ 4 (ядро ≥ 6.7); namespaces требуют root или разрешённых user namespaces.

## Что это меняет в ближайшей работе

Можно продолжать в WSL2 Ubuntu, зная, что это **не привязка**: собираем статический бинарник, проверяем
векторы, а перенос на любое ядро — копирование файла. Установка ОС на железо остаётся заблокированной
диском (17,1 ГБ) и не нужна для этого пути.
