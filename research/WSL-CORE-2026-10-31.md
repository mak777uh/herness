# WSL2 как среда ядра: замеры (31.10.2026)

Проверял не «удобно ли», а хватает ли примитивов для Rust-ядра с песочницей.

## Факты

| что | значение | как получено |
|---|---|---|
| ядро | **6.6.114.1-microsoft-standard-WSL2** | `uname -r` |
| **Landlock** | **есть**, 70 символов в ядре | `grep -c landlock /proc/kallsyms` |
| namespaces | user, pid, mnt, net, ipc, uts, cgroup, time — **все** | `ls /proc/self/ns` |
| cgroup | **v2** (`cgroup2fs`) | `stat -fc %T /sys/fs/cgroup` |
| init | **systemd** (PID 1 = init) | `ps -p 1 -o comm=` |
| seccomp | поддерживается, фильтров по умолчанию нет (`Seccomp: 0`) | `/proc/self/status` |
| Rust | **cargo 1.99.1**, установлен rustup, профиль minimal | `cargo --version` |
| место | 952 ГБ свободно на ext4 (`/dev/sdd`) | `df -h` |
| `/mnt/c` | DrvFs, 23 ГБ свободно, **медленный** | `df -h /mnt/c` |

## Что уже собрано и проверено

`core-rs` — первый срез ядра: канонический JSON, хеш-цепочка журнала, канонизация печати.

```
cargo test
running 3 tests
test result: ok. 3 passed; 0 failed
```

Тесты сверяют **замороженные векторы Python** (`tests/vectors/journal.json`, `seal.json`):
`journal_chain_matches_python`, `seal_matches_python`, `crlf_and_lf_agree`. То есть Rust и Python
согласуются **по байтам**, а не по договорённости.

## Где WSL2 действительно ограничивает

1. **Гость, а не хозяин.** Windows засыпает или перезагружается — прогоны рвутся. Для 24/7 нужен либо
   keepalive, либо Linux на железе/VPS позже.
2. **Диск — образ** (`ext4.vhdx`): бэкап и перенос требуют экспорта; артефакты нужно дублировать вне.
3. **Ядро — сборка Microsoft 6.6.** ADR-0033 (6.18 LTS) к WSL **не применяется**: 6.6 даёт Landlock,
   но новые ABI (ограничения сети, появившиеся позже) недоступны. Для сетевой песочницы это потолок.
4. **`/mnt/c` медленный**: репозиторий и артефакты — только на ext4 (обнаружено на практике: `~/herness`
   оказался симлинком на `/mnt/c`, пришлось собирать в `~/work/herness`).

## Вывод

**WSL2 Ubuntu 24.04 — да, как среда сборки и первого запуска ядра.** Примитивы песочницы есть,
тулчейн работает, векторы сошлись, обратимость полная.

**WSL2 — нет, как единственная ОС харнесса.** Это гость с чужим ядром и диском-образом; долгие прогоны
и «железная» песочница (сеть, cgroup-политики) упираются в его пределы.

Решение об ОС на железе (D2) остаётся открытым и **не блокирует** ядро: контракт — байты, а не платформа.
