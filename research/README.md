# research/ — куда складывать ответы моделей

```
research/
  answers/
    P1/<модель>.md
    P2/<модель>.md
    P3/<модель>.md
    P4/<модель>.md
    P5/<модель>.md
  DIGEST-<тема>.md
```

Правила:

1. **Сырые ответы не редактируются.** Если модель ошиблась — это видно в разборе, а не в
   подчищенном файле (P7: append-only).
2. Первая строка файла — модель и дата: `gpt-5 / 2026-10-29`.
3. Вторая строка — сколько источников модель привела (считаем сами, не по её слову).
4. В дайджест идёт только то, у чего есть источник и дата.

Дайджест (`DIGEST-*.md`) — не пересказ, а таблица: утверждение | источник | кто подтвердил |
степень доверия. Плюс раздел «расхождения» и «чего эти ответы не решают».
