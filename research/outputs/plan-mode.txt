# Режим «план»: первая проверка на живой задаче

Задача: «Составь план: как найти в комнате утверждение C-0196 и проверить его тип. Ничего не меняй».

| условие | результат |
|---|---|
| ни одного вызова `write` | **выполнено** — 0 вызовов |
| шагов в плане ≥ 3 | **выполнено** — 5 шагов |
| есть раздел «неизвестно» | **не выполнено** — раздела нет |

План составлен за 3 шага, опора найдена (`C-0196`), приёмка по критерию — PASS.

# Что это значит:
#   режим «план» работает в главном: агент изучает и предлагает, ничего не меняя.
#   Два условия из трёх выполняются без всякой подсказки.
#   Третье («неизвестно») — требование спецификации, и в протокол комнаты оно ещё не внесено:
#   модель о нём просто не знает. Это граница между «спецификация написана» и «режим работает».
#
#   По дороге исправлен дефект проверки: шаги считались только по строкам, начинающимся с цифры,
#   а план пришёл одной строкой с нумерацией внутри («1) … 2) …»). Теперь считаются оба вида (F-0070).
