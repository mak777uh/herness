# Опора по ссылке «файл:строка» — закрытие класса F-0037 / F-0060 / F-0068

Три отказа одного класса: модель ссылается на источник по-своему, а приёмка сверяет слова.

| отказ | что было |
|---|---|
| F-0037 | опора сверялась по всему токену, а не по совпадению |
| F-0060 | опора возвращала имя из результата, а не токен из ответа |
| F-0068 | модель называет «файл:строка», но не повторяет предмет вопроса |

# Что сделано
#   Третий канал опоры: если в ответе есть ссылка «путь:строка» и такая строка есть в результатах
#   инструментов, ссылка засчитывается как опора. Это то, что делает человек — смотрит туда,
#   куда сослались, а не ищет слова в ответе.
