# Гейт автономии: проверка отказа (отрицательный контроль)

Гейт без проверенного отказа не считается работающим, поэтому контроль записан:

| что подаём | ожидание | результат |
|---|---|---|
| CITATION.cff (защищённый, без записи в журнале) | отказ, exit 1 | exit 1, сообщение «защищённый путь без записи» |
| README.md (обычный путь) | пропуск | exit 0 |
| docs/decision-log.md (защищённый, есть запись) | пропуск | exit 0 |
| lab/autonomy-rules.json (структура) | без проблем | [ok] структура правил автономии |

# Найдено при первом прогоне: проверка «путь упомянут в журнале» срабатывала на шапке журнала,
# где CITATION.cff перечислен как пример защищённого пути. То есть гейт открывался собственным
# описанием. Исправлено: путь сравнивается с ПОЛЕМ строки, а не ищется в тексте.

# Врезка: python bin/hs.py gates → «[ok] автономия: 0 проблем».
