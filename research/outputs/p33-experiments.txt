# Эксперименты P33: конвейер доверия на существующих инструментах

Гипотеза: конвейер (реестр → pre-flight → canary → рабочий набор → отказ) можно построить и
проверить, не имея исполнения кода.

| эксперимент | результат |
|---|---|
| E1. Реестр append-only | 6 инструментов с контрактом, хешем среды и происхождением; отрицательный контроль 3 из 3 |
| E2. Pre-flight по имени и контракту | 5 из 5 случаев; поиск по контракту находит, когда имя не названо |
| E3. Canary и протухание по событию | смена манифеста → все stale; содержимое образа при том же манифесте не видно |
| E4. Рабочий набор и архив | вытеснение сохраняет инструмент искомым; отсутствующий не выдумывается |
| E5. Отказ как протокол | 4 из 4: три невыполнимые задачи дали BLOCKED, выполнимая — done |

# Что это доказывает:
#   конвейер строится и проверяется на существующих инструментах, без исполнения кода.
#   Отказ работает: на невыполнимых задачах модель не выдумывает ответ.
#
# Что это НЕ доказывает:
#   что поиск по контракту лучше поиска по имени — на 6 инструментах разницы не измерить;
#   что лимит рабочего набора (3) правильный — число взято как пример;
#   что canary ловит деградацию содержимого образа — хеш считается по манифесту.
