ГРАНИЦЫ
PASS относится к перечисленным классам входов и этой машине, не к формальной тотальности HTTP-парсера и не к произвольному upstream-серверу.
Half-close — явное требование canonical client subset; клиент без half-close получает timeout без dispatch.
Rust bridge client принимает только IP literal; DNS/hostname исключены из контракта.
Rust response timeout снова настраиваемый (default 180 с); inbound bridge по-прежнему header idle 5.0 с и total 30.0 с. Timing tests проверяют нижние границы, а не точную латентность ОС; отдельные stall-мутанты для фаз body и EOF после полного body не выполнялись.
Upstream provider остаётся полным urllib/TLS контуром; этот эксперимент не делает его canonical HTTP subset.
Doctor остаётся 4/5 из-за access denied при перемещении disk cache установленного DeepSeek Harness; установленный DSH и его ~/.dsh не трогались.
W10 CI-run и clean-clone ещё не выполнены; VSOCK-WIN-R1 — отдельная незакрытая проба.
