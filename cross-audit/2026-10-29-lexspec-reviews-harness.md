## H-1 (MEDIUM) — гейты есть, исполнителя на push нет

**Что обещает контракт.** `AGENTS.md` §2: «Публикация — только после гейтов. `python bin/hs.py gates` должен быть
зелёным; гейт не ослабляется, чтобы „стало зелёным“».

**Что в дереве.** Ни одного workflow:

```
$ ls .github/workflows
ls: cannot access '.github/workflows': No such file or directory
$ ls tests/test_*.py | wc -l
12
```

**Почему это находка.** Правило «перед публикацией прогони гейт» — это обязанность **автора**, а не механизм: она
исполняется памятью и не оставляет следа в коммите. Первый же коммит, сделанный в спешке или другим агентом,
оставит `C-0006` истинным по форме и ложным по факту, и узнать это будет неоткуда — реестр читается как зелёный.
Сейчас все девять гейтов зелёные, и именно поэтому цена ошибки видна только после того, как она случится.

**Что предлагаю.** Один workflow на `push`/`pull_request`, повторяющий ровно то, что уже написано в `AGENTS.md`:
`gates`, `selftest`, `bin/count.py`. Ноль новой логики — только место, где её слушают.

## H-2 (MEDIUM) — гейт «утверждения» зелёный на таблице, у которой шапка не описывает строки

**Воспроизведение.**

```
$ python - <<'PY'
import pathlib
lines = pathlib.Path('CLAIMS.md').read_text(encoding='utf-8').splitlines()
hdr = [l for l in lines if l.startswith('| id ')][0]
rows = [l for l in lines if l.startswith('| C-')]
print('шапка:', hdr.count('|'), '| строки:', {r.count('|') for r in rows})
PY
шапка: 7 | строки: {7, 8}
```

**Что это значит.** В шапке шесть колонок, у 34 из 38 строк — семь (последняя, шаблон вида `0\.2\.1-rc\.3`, нигде
не названа). `gate_claims` проверяет «не меньше шести полей» (`if len(cells) < 6`) и берёт `cells[:6]`, поэтому
седьмая колонка не проверяется и не называется; восемь строк без неё проходят по другой причине, и разница между
ними нигде не зафиксирована.

**Почему это находка, а не косметика.** Разбор «по шапке» сдвинет дату в колонку артефакта, и гейт этого не
заметит — он читает позиционно до шести. То есть у реестра нет ни названной схемы, ни проверки на её соблюдение;
есть только совпадение, которое держится привычкой.

**Что предлагаю.** Назвать седьмую колонку (`grep`) либо убрать её; и добавить в `gate_claims` одну строку:
`if len(cells) != len(header_cells): problems.append(...)`. Это дешевле, чем ловить сдвиг глазами через месяц.
