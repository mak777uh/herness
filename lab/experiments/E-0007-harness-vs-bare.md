# E-0007 — Обвязка против работы без обвязки

Гипотеза (H-0006): обвязка (журнал, утверждения, границы, отчёт) ускоряет и улучшает не все задачи,
а только те, где цена ошибки высока.

## Зачем

Сейчас все утверждения о пользе харнесса не имеют контрольной группы. Это делает их верой. Нужен
базовый уровень, с которым можно сравнивать.

## Пре-регистрация (объявлено до прогона)

**Задачи:** 6 штук из журналов, по два класса:

| класс | примеры |
|---|---|
| простые | переименовать файл; собрать список файлов по шаблону |
| средние | проверить документ на числа без команд; найти расхождение между README и кодом |
| сложные | аудит утверждений репозитория; подготовка отчёта с границами |

**Условия:**

| | A: без обвязки | B: с обвязкой |
|---|---|---|
| разбор | нет | 3 строки |
| журнал и артефакты | нет | есть |
| утверждения и границы | фраза, если вспомнит | обязательны |
| отчёт | свободная форма | report.md |

**Метрики:** время до результата; число шагов; число ошибок, замеченных проверкой; наличие границ в
результате; воспроизводимость (повтор даёт тот же вывод).

**Порог (объявлен сейчас):** обвязка оправдана для класса, если она даёт **меньше ошибок** или
**больше границ** при времени не более чем в 1,5 раза. Иначе класс переводится в режим без обвязки.
