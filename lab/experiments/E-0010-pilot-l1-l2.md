# E-0010 — Пилот L1 против L2 на задачах из истории

Гипотеза (H-0009): на задачах, где инструменты не нужны, уровень L2 (журнал, артефакт, границы) не
улучшает ответ, но стоит больше шагов.

## Материал

8 задач, извлечённых из журналов (`lab/pilot/T-XX.task.txt`) вместе с эталонным ответом
(`T-XX.ref.txt`). Все — анализ схемы Postgres, где схема дана в тексте задачи; в оригинальных
сессиях у большинства **0 вызовов инструментов**. Это натуральный контрольный срез.

## Дизайн

| режим | что делает исполнитель |
|---|---|
| **L1** | читает задачу, решает, отвечает |
| **L2** | то же + сохраняет ответ в файл + добавляет `not_claimed` + журналирует через `hs step` |

Исполнители разные, задачи одинаковые. Эталон — исходный ответ из журнала.

## Метрики

1. **Совпадение с эталоном**: назван ли тот же ответ (для T-01 — те же два пути обхода).
2. **Число шагов**.
3. **Наличие границ** (`not_claimed`).

## Статус: пилот, не доказательство

По расчёту из `research/DIGEST-control-slice.md`: чтобы отличить 20 % от 10 %, нужно ≈197 задач на
группу. Восемь задач позволяют увидеть только **грубые** различия. Вывод формулируется как
«разницы не обнаружено на 8 задачах», а не «L2 не нужен».

## Результат

первая пара (T-01) запущена 29.10.2026; результат ниже по мере поступления.

## Результат — пара T-01 (29.10.2026)

| | L1 | L2 |
|---|---|---|
| вывод | один рабочий обход (set_balance, SECURITY DEFINER); путь через view мёртв из-за INVOKER-триггера | то же |
| свидетельство | рассуждение по тексту схемы | **прогон на PostgreSQL 17.2**: T3 падает, T7 (триггер SECURITY DEFINER) проходит, T8 (без триггера) проходит |
| цена | несколько шагов | поднятая база, 10 тестов, артефакт и журнал |
| границы | нет | есть (`not_claimed`) |

**Эталон из журнала оказался неверным** (F-0011): он считал путь через view рабочим обходом.

### Главный вывод пары

Правильность **не различалась** — обе группы дали верный ответ. Различие в **свидетельстве**: L1
убеждает рассуждением, L2 даёт воспроизводимый прогон. И цена L2 на этой задаче высокая: база,
десять тестов.

Для маршрутизации это даёт правило: **L2 нужен не для правильности, а для проверяемости чужой рукой**.
Там, где достаточно «мне верю» — L1. Где результат уходит наружу или его будет проверять другой —
L2.

### Статус

Пилот: 1 задача из 8. Судить «L2 не нужен» нельзя — выборка под это слишком мала (см. расчёт:
197 задач на группу для 10 п.п.). Но направление видно.
