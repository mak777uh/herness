# E-0003 — Внешний обзор против самоотчёта

Гипотеза (H-0002): агент, описывающий собственные ошибки, пропускает часть из них; внешний
ревьюер со свежим контекстом находит больше.

## Пре-регистрация (объявлено до прогона)

**Схема.** Берём один завершённый прогон (журнал + артефакты).

1. **Автор** (та же сессия, что вела прогон) перечисляет свои ошибки и недоработки: список пунктов.
2. **Ревьюер** (свежая сессия, только журнал и артефакты, без истории автора) делает то же независимо.
3. **Человек** сводит: какие пункты ревьюера автор пропустил; какие пункты автора ревьюер не подтвердил.
4. Проверяем каждый пункт воспроизводящим случаем: есть команда/вход/ожидание — считается; нет — нет.

**Метрика:** доля подтверждённых ошибок, найденных только ревьюером, и только автором.

**Порог (объявлен сейчас):** гипотеза подтверждается, если ревьюер находит ≥1 подтверждённую ошибку,
которой нет в самоотчёте, и при этом не выдаёт больше ложных пунктов, чем автор.

**Повторы:** три прогона разной длины (короткий, средний, длинный).

## Команда

```
python bin/hs.py run "<прогон для разбора>" --profile headless
```

## Что это не доказывает

- Что ревьюер найдёт ошибки в любом прогоне.
- Что «нашёл больше» означает «нашёл важные».
- Что человек-сводчик не вносит собственных предпочтений.
