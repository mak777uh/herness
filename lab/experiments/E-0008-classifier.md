# E-0008 — Классификатор типов задач

Гипотеза (H-0007): маленькая локальная модель классифицирует типы задач не хуже большого LLM при
заметно меньшей цене.

## Пре-регистрация (объявлено до прогона)

**Данные:** 100–150 реальных запросов из журналов, размеченных человеком по 7 типам (или «неизвестен»).
Разметка — до прогона, не после.

**Участники:**

| вариант | что |
|---|---|
| E | эмбеддинги + центроиды (baseline) |
| B | LLM по таблице типов (эталон) |
| C | 1–3 маленькие модели с HF |
| W | «всегда L1» — контрольный участник |

**Метрики:** macro-F1 по типам; доля «неизвестен»; задержка; размер модели; стоимость вызова.

**Порог (объявлен сейчас):** C годится, если отстаёт от B не более чем на 5 п.п. macro-F1 и
укладывается в ≤50 мс на CPU. Если W не хуже C по итоговой цене задачи — классификатор не вводим.

## Результат

не заполнено.

## Что это не доказывает

- Что 150 примеров достаточно для редких типов.
- Что разметка одного человека совпадает с разметкой другого.
- Что модель перенесётся на новые типы без дообучения.
