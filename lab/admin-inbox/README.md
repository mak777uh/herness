# Очередь находок для админа харнесса

Сюда кладут находки другие проекты и сессии: «застрял», «работает так», «нашёл механизм».
Один файл — одна находка, имя `ГГГГ-ММ-ДД-слаг.md`. Шаблон — `_template.md`.

**Правило:** находка без статуса считается потерянной. Статус ставит админ:
`принято` / `отклонено` / `отложено`, с причиной и ссылкой на запись в `lab/adoptions.json`.

Зачем так: находка не должна зависеть от того, пересказал ли её кто-то в чате. И не должна исчезать,
если про неё забыли — это видно по отсутствию статуса.
