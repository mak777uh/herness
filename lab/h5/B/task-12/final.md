**Fact Check — единственная метрика, которая падает.** По таблице из статьи 2605.06635 (§4.3 / Figure 2):

| вызовов | Fact Check |
|---:|---:|
| 2 | 80.0 % |
| 10 | 74.4 % |
| 30 | 69.2 % |
| 50 | 61.2 % |
| 70 | 61.7 % |
| 100 | 58.7 % |
| 150 | 57.9 % |

Итог: монотонное падение **80 → 57.9 %** (≈ −22 п.п.), тогда как Link Works и Relevant держатся на 92–100 %. То есть при росте числа вызовов деградирует именно фактическая проверяемость, а не доступность ссылок или релевантность.

Оговорка: «−42 %» из абстракта — относительное падение по двум моделям, а не эта таблица.
