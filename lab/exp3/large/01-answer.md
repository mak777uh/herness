# Ответ модели 1 (P14, реестр ОС) — выдержка

«NixOS — поколения системы, `nixos-rebuild switch --rollback`; Guix System — поколения,
`guix system roll-back`; openSUSE Tumbleweed — снимки btrfs (Snapper), `snapper rollback`;
Fedora Silverblue — ostree-деплойменты, `rpm-ostree rollback`; Debian 13 — штатного отката нет;
Ubuntu 24.04 — штатного отката нет.

lean4: в NixOS подтверждён атрибут `lean4`; в Ubuntu его нет, но есть `elan`; для остальных — нет данных.»
