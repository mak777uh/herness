# lab/ — гипотезы, эксперименты, решения

Протокол: боль → источники → рубрика → пре-регистрация → прогон → вердикт.
Порог нельзя придумывать после того, как увидел результат.

```
lab/
  hypotheses/H-XXXX-<slug>.md
  experiments/E-XXXX-<slug>.md
  decisions/ADR-XXXX-<slug>.md
  templates/
```

## Шаблон гипотезы

```
# H-XXXX — <формулировка одной фразой>
Боль: какую дыру закрываем.
Проверка: что и как мерим, до прогона.
Опровержение: какой результат заставит сказать «гипотеза неверна».
Статус: open | confirmed | refuted
```

## Шаблон эксперимента

```
# E-XXXX — <что проверяем>
Гипотеза: H-XXXX
Пре-регистрация: порог/метрика объявлены до прогона.
Среда: ОС, версии, ресурсы (см. `python bin/hs.py facts`).
Команда: <точная команда>
Результат: <числа + дайджест артефакта>
Вердикт: confirms | refutes | inconclusive
Что это не доказывает: <обязательно>
```
