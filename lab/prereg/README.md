# lab/prereg — пре-регистрация гипотез

Взято у Morphogenesis (`docs/cycle.md`, §3c): гипотеза с критерием фиксируется **до** запуска, и
«эксперимент на разницу между плечами» не запускается, пока не посчитана арифметика, которая эту
разницу создаёт.

## Формат файла

`<id>.json`:

```json
{
  "id": "H-0001",
  "date": "2026-10-30",
  "question": "что проверяем",
  "hypothesis": "что ожидаем увидеть",
  "criterion": "что будем считать подтверждением, до каких чисел",
  "arms": ["A: ...", "B: ..."],
  "sensitivity": "почему выбранная метрика вообще может различить плечи: арифметика или довод",
  "runs": ["runs/exp-..."],
  "closed": false
}
```

## Правила

1. **До запуска.** `date` пре-регистрации должен быть не позже даты каталога прогона.
2. **Чувствительность обязательна.** Если написано «плечи могут не различаться» — это честный отказ,
   а не пре-регистрация.
3. **Закрытие только артефактом.** `closed: true` требует `conclusion` — путь к отчёту, где записан
   исход (подтверждена / опровергнута / не проверялась).
4. **Изменение гипотезы после прогона** — новый файл с новым `id` и ссылкой `supersedes`.

## Проверка

```
python bin/prereg.py check      # формат и закрытие
python bin/prereg.py debt       # эксперименты без пре-регистрации
```
