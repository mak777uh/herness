id: F-0060
date: 06.11.2026
title: опора возвращала имя из результата, а не токен из ответа
what: в ветке «найдено по вхождению» claim_anchor возвращал имя ИЗ РЕЗУЛЬТАТА (musique-2), а приёмка ищет опору в ответе; верный ответ с именами без путей получал unverified
class: instrument-error
principle: опора живёт в ответе; в журнал надо писать то, что модель сказала, а не то, что нашлось в результате
detect: ответ, где имя есть в результатах, но записано без пути; проверить, какая строка попала в claim/anchored
test: после правки claim/anchored содержит токен из ответа, задача проходит за 1 шаг
symptom: «в ответе нет ни одного элемента из результатов инструментов» при верном ответе
cause: return Some(found.clone()) вместо Some(token)
fix: возвращать токен из ответа
caught_by: чтение события claim/unverified рядом с верным ответом
