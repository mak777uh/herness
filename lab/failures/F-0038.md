id: F-0038
date: 02.11.2026
title: задача имела три равноправных ответа, и ключ выбирал один по порядку
what: «какой прогон самый длинный» — три выгрузки по 82 строки; генератор брал первую по алфавиту, модель назвала другую и формально была права
class: task-spec
principle: задача с неуникальным ответом не проверяет ничего; ключ обязан быть единственным по построению
detect: посчитать распределение ключа по данным и убедиться, что максимум единственный
test: после переформулировки в «у скольких выгрузок максимум строк» ответ 3 единственен, задача проходит
symptom: верный по существу ответ считается неверным
cause: ключ выбирался как max() по словарю без проверки на равенство значений
fix: ключ строится как мощность множества максимальных значений, а не как имя одного из них
caught_by: разбор ответа, который не совпал с ключом, но опирался на размер файла в list
