id: F-0094
date: 15.11.2026
title: Собственный README не проходит собственную мерку: 7 чисел в прозе, 0 команд рядом
what: Прогон `bin/verify_repo.py .` по своему репозиторию дал 7 строгих утверждений в прозе README и 0 с командой в соседних двух строках. Числа настоящие и воспроизводимые, но команда стоит не рядом с числом, а в другом разделе («Как проверяется») или в блоке чисел, который пересобирает `readme_numbers.py`.
class: doc-drift
principle: требование, адресованное другим, проверяется на себе первым. Если свой README не проходит мерку, мерка либо неверна, либо README врёт о своей проверяемости — и это надо назвать, а не спрятать.
detect: `python bin/verify_repo.py . --json` → `total 7, with_command 0`; в списке — строки про 32 гейта, 33 пробы, strict 0.57, 19 кодов отказа.
symptom: README утверждает числа, которые можно воспроизвести, но читатель не видит, чем именно — команды лежат в другом разделе; прибор, читающий окно ±2 строки, этого не видит.
cause: числа писались как прозаические утверждения, а команды — как список в разделе проверок; связи «число → команда» в тексте нет.
fix: в раздел «Чего это не доказывает» добавлена строка с результатом самоизмерения и указанием, где лежат команды. Форма не менялась задним числом: цифра 7/0 — это снимок README на 15.11.2026.
not_proven: исправление не делает README проверяемым по мерке — оно делает разрыв видимым. Чтобы 7 стало 7 с командами, нужно ставить команду вплотную к каждому числу, а это переписывание README, а не правка строки.
cost: читатель верит числу, потому что рядом стоит ссылка на CLAIMS.md, а не потому, что может его пересчитать.
trap: «у нас же есть раздел «Как проверяется»» — есть, но не там, где число.
check: `python bin/verify_repo.py . --json | python -c "import json,sys; d=json.load(sys.stdin); print(d['total'], d['with_command'])"`
test: python bin/verify_repo.py . --json → total 7, with_command 0 (снимок README на 15.11.2026); повторный прогон даёт те же числа, кроме generated_at.
caught_by: самоизмерение 15.11.2026 — прогон прибора по своему репозиторию после пяти чужих; гейты этого не ловят, потому что прибор не входил в гейты.
