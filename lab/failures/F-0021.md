id: F-0021
date: 2026-10-31
what: инструмент `exec` с allowlist из одного пути `/init` позволял модели запустить нашу же программу в режиме цикла — то есть запустить второй цикл внутри первого; прогон уходил в OOM при 256 и при 768 МБ памяти
class: recursion-by-design
principle: инструмент, который умеет запускать только нас самих, даёт не силу, а рекурсию; «разрешено» должно означать «имеет смысл», а не «существует»
detect: ядро печатало "Out of memory and no killable processes" сразу после монтирования диска; в журнале моста при этом было 4 запроса модели, то есть цикл успел уйти вглубь
test: exec удалён из набора инструментов; дочерним процессам ставится HS_LOOP_ACTIVE=1, и loop-bridge при этом признаке отказывается стартовать
caught_by: ядро печатало "Out of memory and no killable processes" сразу после монтирования диска; в журнале моста при этом было 4 запроса модели, то есть цикл успел уйти вглубь
cost: два прогона по 90 секунд впустую; до этого exec был объявлен «сделано» без прогона с ним
