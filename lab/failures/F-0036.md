id: F-0036
date: 02.11.2026
title: в образ попали выходы оценщика, и модель ответила строкой из нашего же отчёта
what: на вопрос о состоянии ADR-0052 ответ был «FAIL (НЕВЕРНО): …/history-baseline.txt:9», то есть цитата из прошлого прогона, а не из файла решения
class: instrument-error
principle: комната не должна содержать результатов оценки; иначе агент может отвечать ими, и приёмка теряет смысл
detect: искать в образе каталоги с выходами оценщика (research/outputs) и сверять ответы с их содержимым
test: после удаления research/ из образа ответ стал «docs/ADR-0052-flail-is-diagnostic.md:3 — «Состояние: принято»»
symptom: верный по форме, но неверный по источнику ответ; приёмка PASS при ответе из отчёта
cause: в образ скопировали research/outputs
fix: образ без research/; в комнату кладутся только первичные артефакты
caught_by: чтение ответа — он цитирует наш отчёт
