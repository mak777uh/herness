id: F-0063
date: 06.11.2026
title: проверял модели не у того провайдера
what: владелец сказал «commandcode», а я пошёл в OpenRouter, где стелс-модель недоступна по региону; на commandcode те же модели доступны и каталог открыт без ключа
class: instrument-error
principle: имя провайдера — часть условия задачи; проверять надо тот, который назван
detect: сверить адрес из конфигурации профиля (cordis.patch.yml) с адресом, по которому идёт запрос
test: api.commandcode.ai отдаёт 95 моделей без ключа, включая stealth/crouton-alpha
symptom: вывод «модель недоступна», хотя у названного провайдера она есть
cause: взял первый найденный ключ (openrouter) вместо названного провайдера
fix: проверять провайдера из конфигурации, а не из доступных ключей
caught_by: указание владельца
