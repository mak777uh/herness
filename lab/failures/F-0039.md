id: F-0039
date: 02.11.2026
title: min_objects наказал эффективность: верный ответ за два шага был отвергнут
what: задача «сколько выгрузок содержат run/blocked» решалась поиском за 2 шага с верным ответом, но требование трёх объектов дало отказ
class: instrument-error
principle: проверка не должна требовать больше работы, чем нужно для ответа; иначе она поощряет трату шагов
detect: подложить задачу, где ответ получается за один-два шага, и убедиться, что проверка её не режет
test: после снятия min_objects с этой задачи она проходит за 3 шага; на подсчёте классов отказов требование сохранено
symptom: верный ответ считается непринятым, шаги растут без пользы
cause: min_objects считал объектами любые аргументы вызовов, включая поисковые запросы
fix: требование применяется только там, где ответ по построению невозможен без многих объектов
caught_by: разбор ответа «верно» при отказе приёмки
