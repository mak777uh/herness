# ADR-0043. Всё в комнату: набор инструментов из первых принципов

**Статус:** принято 31.10.2026. Решение владельца — вариант **B**; ниже следствия и выбор
инструментов, а не обоснование самого B.

## Что означает B

Цикл, инструменты и свидетельства живут в одной гостевой системе. Следствия, которые нельзя
отложить:

1. **Сеть в ядре** — вариант D: +573 440 Б (C-0127), образ 1,50 → 2,06 МБ.
2. **Правило на UDP обязательно** — Landlock ABI 7 закрывает только TCP; без правила сеть в
   песочнице означает неограниченный UDP (C-0130).
3. **Провайдер на Rust** — Python в комнате нет (ADR-0042); HTTP-клиент и TLS придётся тащить в
   бинарник, цену надо померить.
4. **Транспорт хост→гость больше не нужен** — это и есть выигрыш B: нет моста, нет двух машин.

## Правила выбора инструментов

- **R1. Инструмент — примитив, а не удобство.** Он существует, только если шаг нельзя выразить
  другими инструментами.
- **R2. Привилегия должна выражаться политикой** (пути, адреса, лимиты). Если привилегию нельзя
  выразить — это не инструмент, а дыра.
- **R3. Каждый вызов пишется в журнал**: имя, аргументы, код, байты, длительность. Инструмент без
  записи — не инструмент харнесса, а просто функция.
- **R4. Инструмент, умеющий всё, обнуляет политику остальных.** Тогда политика переезжает на
  уровень ОС (Landlock/seccomp), либо инструмент исключается.

## Набор

| инструмент | примитив | зачем (наш замер, 594 вызова) | привилегия | цена образа |
|---|---|---|---:|---|
| `read` | байты из файла | 212 вызовов (36 %) | пути | 0 — в бинаре |
| `write` | байты в файл | правки | пути, только рабочий каталог | 0 |
| `list` | имена в каталоге | 115 (19 %) | пути | 0 |
| `search` | поиск по содержимому | 50 (8 %) | пути + шаблон | 0 |

Шесть примитивов. Всё остальное — либо их композиция, либо чужая задача.

## Что не переезжает и почему

- **`shell`** — композиция, а не примитив (R1). И цена измерена: статический busybox
  **2 124 608 Б**, больше нашего ядра (1 496 064 Б). Начинаем без shell: `exec(program, argv)` без
  пайпов и глобов. Если реальные задачи потребуют композиции — добавляем, но тогда политика
  переезжает на Landlock+seccomp (R4), а не на наши инструменты.
- **`browser`/CDP** — нужен живой Chrome и сессия владельца; в комнате его нет и не будет.
- **`git`** — это `exec` над бинарём, если бинарь есть. Отдельного инструмента не нужно.
- **Пакетные менеджеры** — сеть и доверие к чужим индексам; не сейчас.

## Что это обязывает сделать до первого запуска B

1. **UDP-правило** — seccomp на `socket(AF_INET, SOCK_DGRAM)` с маской типа, иначе сеть дырявая.
2. **Замерить цену TLS** в Rust: если `rustls` добавит ~1 МБ, оценка B меняется (образ станет ~3 МБ).
3. **Реестр инструментов с записью в журнал** (R3) — иначе шесть инструментов станут шестью
   способами соврать.

## Границы

- Числа вызовов — наши прогоны, а не «индустрия»: 594 вызова в `runs/**/events.jsonl`.
- Цена TLS не измерена; это единственная неизвестная в цене B.
- Набор выбран по нашим задачам (правка кода, чтение, поиск, запуск). Задачи, которых мы не делали,
  могут потребовать инструментов, которых здесь нет, — и это будет видно по журналу отказов.
