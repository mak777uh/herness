# Проверка опоры: измерение ошибок и исправление

**Дата:** 08.11.2026. **Основание:** ресёрч (OpenAI SWE-bench audit: 59,4 % тестов отвергали
правильные решения; аудит 496 траекторий: 18,5 % расхождений) и собственный замер.

## Что сделано

**199 контрольных случаев** (lab/oracle/cases.json), где правильность ответа записана
**заранее** и не зависит от проверки. Восемь классов: прямое совпадение, числа словами,
перефразирование, несколько источников, неполные источники, граничные, противоречащие,
некорректные ссылки.

**Прогон** (in/oracle_run.py) меряет только проверку опоры: FNR, FPR, разбивку по классам.

## Результат до исправлений

| | |
|---|---|
| FNR (правильных отвергнуто) | **50 %** |
| FPR (неправильных принято) | 1,8 % |

**Проверка отвергала половину правильных ответов.** Это ровно то, о чём предупреждает ресёрч.

## Четыре найденных дефекта

**1. Опора смотрела только последний результат.** Агент читал три файла и отвечал по первому —
опоры нет. **77 % ложных отказов** в классах multi и paraphrase.

**2. Вхождение проверялось в одну сторону.** ADR-0001 не находился в ADR-0001-test.md.
**50 % ложных отказов** в классе direct.

**3. Число из одной цифры отбрасывалось.** Порог «три знака» отсекал ответ «3».
**60 % ложных отказов** в классе number-word.

**4. Длина в 
umber_word бралась из таблицы в символах, а сравнение шло в байтах.**
Для кириллицы 1 символ = 2 байта, поэтому «три» (3 символа, 6 байт) не находилось никогда.

## Результат после исправлений

| | было | стало |
|---|---|---|
| FNR | 50 % | **1,9 %** |
| FPR | 1,8 % | 1,8 % |
| правильных принято | 57 | **141** |
| неправильных отвергнуто | 55 | 55 |

**По классам:** direct 0 %, multi 0 %, number-word 0 %, edge 0 %, incomplete 0 %,
contradict 0 %, badref 0 %, paraphrase 7 % (2 из 30).

## Что это значит

**FPR не вырос.** Неправильные ответы по-прежнему ловятся (55 из 55). Проверка стала
**точной**, а не слабой.

## Граница

**Модель на Python** (in/oracle_anchor.py) повторяет правила Rust. Замер сделан на модели;
совпадение с Rust подтверждается тестами (52 проходят) и прогоном в комнате, а не доказательством.

## Что дальше

**2 случая paraphrase** остались. Это 7 % — не критично, но записано.

**Правило на будущее:** любой гейт проверять **положительным** контролем (правильный ответ
должен приниматься), а не только отрицательным (дефект должен ловиться).
