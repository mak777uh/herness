# QUESTIONS — что нужно понять до первой строки кода

Дата: 29.10.2026. Два контура, их нельзя смешивать:

- **A. К владельцу** — решения. Ни одна модель их не заменит: это про цели, риски и вкус.
- **B. К моделям** — исследование. Отвечается ссылками на первоисточники, а не мнением.

Правило: пока вопрос из A не отвечен, ответ из B на него не влияет. Иначе модели начнут
проектировать харнесс за владельца.

## C. Протокол агрегации пяти ответов

1. **Один промпт — пять моделей.** Сырые ответы сохраняются как
   `research/answers/<prompt-id>/<model>.md`, без правок.
2. **Разбор по строкам, не по абзацам.** Каждое утверждение → строка: `утверждение | URL | дата
   источника | кто из моделей сказал`.
3. **Классификация строк:**
   - источник есть и открывается → `observation`;
   - источник есть, но противоречит тексту модели → отбросить, записать в расхождения;
   - источника нет → `judgment`, в вывод не идёт;
   - модели расходятся → **не усредняем**, выносим в открытые вопросы.
4. **Порог доверия:** совпало у ≥3 моделей **и** подтверждено источником → идёт в дайджест.
   Один источник → идёт с пометкой «единственный источник».
5. **Запрещено:** складывать популярность из звёзд без даты; верить числам без ссылки;
   считать «все говорят» свидетельством.
6. **Итог:** `research/DIGEST-<тема>.md` — таблица, где у каждой строки источник и графа «кто
   подтвердил». В конце — «что эти ответы не решают».

## D. Чего эти вопросы не решают

- Не заменяют замер на нашей машине (E-0001): чужие бенчмарки — не наши условия.
- Не решают вопрос вкуса владельца (A1–A12).
- Не гарантируют, что завтра не выйдет харнесс, который делает то же лучше.
- Не отменяют правило P17: ответ модели — гипотеза, пока не проверена прогоном.
