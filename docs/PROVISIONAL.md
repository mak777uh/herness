# PROVISIONAL — что здесь леса, а что уже стоит

Центр системы — **диалог** (модель + владелец). Харнесс — его осадок: то, что после диалога
доказало повторяемость. Значит всё остальное — гипотезы о будущем, и они должны быть помечены,
иначе леса становятся догмой.

## Два статуса

| статус | что значит | что с ним делают |
|---|---|---|
| **кристаллизовано** | есть свидетельство: прогон, тест, замер, повтор | защищается гейтом, меняется через ADR |
| **провизионно** | записано как намерение; свидетельства нет | пересматривается каждый цикл: кристаллизуется или удаляется |

Правило: **провизионное решение обязано иметь условие кристаллизации** — что именно должно
произойти, чтобы оно перестало быть намерением. Без этого условия оно не провизионное, а забытое.

## Текущая разметка

### Кристаллизовано (есть свидетельство)

| что | свидетельство |
|---|---|
| контракты: утверждение без типа и границы невозможно | 20/20 тестов |
| M1: артефакт раньше ответа модели | 5/5 тестов, порядок событий |
| гейты: секреты, утверждения, ссылки, критерии, аудит | `hs gates` 5/5 |
| реестр критериев: нет строки без способа установления | `hs criteria` |
| справочник: портфель + внешние источники | `hs refs list`, 34 документа |
| разбор запроса: неопределённость без закрытия отбивается | `hs request --corpus` 4/4 |
| аудит: заметка без repro — не находка | `hs audit`, 5/5 тестов |

### Провизионно (намерение, свидетельства нет)

| что | условие кристаллизации | если не сбудется |
|---|---|---|
| ADR-0009: харнесс как системный слой | H1: две службы под супервизором, падение одной не роняет другую | удалить, оставить «приложение» |
| ADR-0011: минимальная конфигурация ядра | H0b: ядро ≤250 МБ, загрузка ≤3 с, тулчейны работают | вернуться к обычному дистрибутиву |
| ADR-0010: один образ в четырёх формах | H0: сборка dir/tar/qcow2/raw | оставить контейнер + WSL |
| ADR-0006: поколения и откат | M10: сломанное поколение откатывается само | самоизменение отложить |
| ADR-0012: язык по слоям | E-0002: цена итерации у Python vs Rust/Go | пересмотреть L2 |
| ADR-0013: резервные маршруты | T1: onion-вход за NAT работает | оставить релей |
| ADR-0016: DSL границ | E-0004: три нотации на трёх границах | остаться на схеме |
| G5 «импакт на единицу времени» | метрика определена и снята | заменить на измеримый прокси |

## Риски, которые это лечит

1. **Догма из намерения.** ADR, написанный до проверки, начинает цитироваться как факт.
2. **Накопление без отсева.** Каждый цикл добавляет документы, ни один не удаляется.
3. **Путаница статусов.** «Мы решили» смешивается с «мы проверили».

## Правило цикла

Раз в цикл:

1. взять все провизионные пункты;
2. спросить: появилось ли свидетельство;
3. появилось → кристаллизовать (тест/замер) и убрать из этого файла;
4. не появилось и не планируется → **удалить**, а не хранить;
5. перенести причину в `docs/eliminations.md`.

Удаление — нормальный исход. Документ, который никто не собирается проверять, стоит дороже, чем
его отсутствие: он создаёт вид определённости.
