# ADR-0021 — Классификатор типов задач: маленькая модель, но сначала разметка

Дата: 29.10.2026. Статус: предложено. Дополняет ADR-0020.

## Задача

Раскладка запроса на типы задач. Регулярки провалились: 82,8 % нераспознанных на 58 реальных
запросах (K95). Нужен классификатор, который работает на живом языке — русском и английском вперемешку,
на коротких и длинных текстах.

## Варианты

| вариант | плюсы | минусы | когда годится |
|---|---|---|---|
| **A. Регулярки** | ноль стоимости | 83 % промахов (измерено) | только явные команды |
| **B. Большой LLM** (через агента) | понимает смысл, ноль обучения | цена вызова, задержка, зависимость | сейчас, мало запросов |
| **C. Маленькая модель с HF** | быстро, офлайн, дёшево, приватно | нужен корпус для выбора и проверки | когда есть ≥100 размеченных |
| **D. Дообучение своего** (JEV-подобный) | под наш словарь и смесь языков | данные + время + поддержка | когда C не хватает точности |
| **E. Эмбеддинги + центроиды** | без обучения, 10 строк кода | точность ниже, чувствительна к формулировкам | как baseline для сравнения |

## Порядок, а не модель

Главный дефицит — не модель, а **размеченный корпус**. Пока его нет, любой вариант не проверяем.

| шаг | что | критерий |
|---|---|---|
| 1 | собрать 100–150 реальных запросов из журналов | каждый размечен типом (или «неизвестен») человеком |
| 2 | прогнать E: эмбеддинги + центроиды | baseline точности |
| 3 | прогнать B: LLM-классификация | эталон качества и цены |
| 4 | прогнать C: 1–3 маленькие модели | сравнение с эталоном по точности и задержке |
| 5 | решить | если C не хуже B на 5 п.п. — берём C |

## Требования к модели (если C)

- **CPU-only**, без GPU: хост может быть без видеокарты.
- **≤150 МБ** в квантованном виде: место на диске не бесконечно.
- **≤50 мс** на запрос: классификация не должна быть узким местом.
- **смесь ru/en**: запросы владельца двуязычны.
- **офлайн**: без сетевых вызовов, чтобы не зависеть от канала.
- **лицензия**: разрешать локальное использование без ограничений.

## Ловушка, которую надо назвать

Классификатор может оказаться **не нужен**. Если правило «всегда L1, повышаем по провалу»
показывает ту же цену, что и профили — профили не стоят своей сложности. Это объявлено заранее:
сравнение с «всегда L1» обязательный участник.

## Что это не доказывает

Что маленькая модель достижима по точности. Что 7 типов достаточно. Что разметка одного человека
не предвзята: типы придумал тот же, кто размечает.
