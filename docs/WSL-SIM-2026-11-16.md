## Caveats

- WSL is not a security boundary: it runs as root and is not the owner's laptop.
- The room tool is trusted code. bwrap hides /mnt/c and /etc/passwd and removes network, but K1/K2 are enforced by the tool, not by a kernel room; /etc/ld.so.cache and the IPC directory remain visible.
- Bridge destinations are Unix sockets behind the bridges; no real Internet egress is tested.
- The tool hardcodes the only bridge socket; the card-side bridge declaration and bridge registry are not modeled.
- Bridge resource limits (K4) are not enforced; only the head output cap is tested.
- K6 recognizes only the fake fixture patterns; it is not a general secret detector.
- K9 is a policy check; it does not inspect downstream code or prove the absence of hidden egress.
- K11 checks a hash-bound approval record; it does not judge intent and never executes the foreign package.
- Raw read of the secret/key is a CONTROL: it shows that the unfiltered path violates K6. Only the filtered path passes.
- The host firewall/network was not changed and is not tested; the simulation does not ban the owner's laptop.
