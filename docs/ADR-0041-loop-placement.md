# ADR-0041. Где живёт цикл: голова снаружи, руки внутри, сети — нигде

**Статус:** принято 31.10.2026 по приор-арту и нашим замерам. Закрывает развилку A/B.

## Контекст

Мы построили песочницу: своё ядро 6.18.60, `hs-core` как PID 1, журнал на ext4, цикл-скелет внутри
(ADR-0040). Но настоящий цикл и инструменты до сих пор исполняются на хосте — то есть **радиус
нашей границы сейчас ноль**: команда, которую я запускаю, имеет полные права Windows.

Выбор был между A (голова снаружи, руки в песочнице) и B (всё внутри).

## Что говорит приор-арт

Три точки размещения: цикл на хосте с изоляцией отдельного вызова; весь агент в контейнере/VM;
цикл в облаке, исполнение на отдельной машине.

| паттерн | кто | чем подтверждено у нас |
|---|---|---|
| цикл на хосте, песочница вокруг исполнения | Codex CLI | **тело источника**: helper использует `bubblewrap` + `seccomp`, Landlock остаётся legacy-реализацией; WSL2 идёт обычным путём, WSL1 отвергается |
| весь агент в контейнере | OpenHands | **тело источника**: «client-server architecture implemented with Docker containers», песочница для произвольного кода; **где именно цикл — из документа не следует**, отчёты агентов здесь расходятся |
| цикл в облаке, исполнение на машине | Devin (Brain/DevBox) | только по словам агентов |
| цикл на хосте | Claude Code, Gemini CLI | только по словам агентов: `code.claude.com` с этой машины не открылся |

Вывод приор-арта: доминирует **цикл на хосте + изолированное исполнение**, и вопрос не «хост или
VM», а **радиус границы** и список того, что осталось снаружи.

## Решение

**A.** Цикл (вызов модели, планирование) — на хосте. Инструменты (файлы, процессы) — в гостевой
системе. **Сети в гостевой системе нет вообще**, конфиг остаётся C (+`virtio-rng`).

## Почему

1. **Совпадает с доминирующим паттерном** и не требует изобретать размещение.
2. **У нас есть то, чего нет у них: песочница без сети.** У Claude Code и Codex egress идёт через
   прокси вне песочницы — то есть канал существует и его надо ограничивать политикой. У нас канала
   нет: UDP не нужен потому, что нет стека. Это сильнее любого allowlist.
3. **Секреты не входят в границу.** Урок Devin Outpost: токен внутри контейнера читается кодом
   сессии. У нас ключ провайдера остаётся на хосте и в гостя не попадает никогда.
4. **Свидетельства остаются внутри.** Журнал — не секрет, ему место рядом с действием.

## Что это обязывает построить (без этого решение — только бумага)

- **транспорт хост → гость** (vsock, 9p или последовательный канал) — сейчас его нет;
- реестр инструментов внутри гостя (сегодня один: `seal`);
- правила песочницы: что можно писать, что читать, чем ограничен процесс (Landlock-политика).

## Что отвергнуто и когда пересмотрим

**B отвергнут сейчас:** +573 440 байт к ядру, UDP-дыра, которую надо закрывать seccomp-правилом,
HTTP-клиент на Rust и ключ провайдера внутри границы — ради «одной машины вместо двух».

Пересмотреть, если: (1) замер покажет, что мост хост↔гость дороже прямого вызова модели; (2)
понадобится работа без хоста вообще (тогда B — единственный вариант).

## Границы

- Приор-арт — **документация вендоров, а не измерения**. Что один паттерн безопаснее другого при
  одинаковой модели угроз, из этих документов не следует, и я это не утверждаю.
- Один из четырёх источников не открылся с этой машины; его факты остаются «по словам агентов» и в
  реестре утверждений не участвуют.
- Наша песочница сейчас **не защищает ничего**: инструменты ещё на хосте, транспорт не построен.
