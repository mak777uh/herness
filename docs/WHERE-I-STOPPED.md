## Стандарт передачи смены (handoff)

Один rolling-документ (этот файл), **без архива и без параллельных реестров**: очередь живёт в
`lab/queue.json` (+ `python bin/hs.py supervise check`), решения — в `docs/decision-log.md`,
утверждения — в `CLAIMS.md`, опыты — в `lab/registry.json`. Handoff не дублирует их, а **ссылается**
и даёт точную точку продолжения.

Цикл смены: **BOOT** (ветка/HEAD/дерево/origin) → **RECONCILE** (сверить документы с кодом и артефактами,
устаревшее не принимать за истину) → **SELECT** (одна задача из очереди; блокировку не обходить) →
**PREREGISTER** (порог ДО прогона) → **EXECUTE** → **VERIFY** (команды+гейты; отделить проверенное от
предположений) → **HANDOFF** (обновить этот файл по шаблону ниже).

Главное правило: evidence — **внешне-воспроизводимый артефакт + команда**, а не собственная проза
(урок `gate_selfref` / F-0089: прибор не должен льстить себе). Следующий агент получает не рассказ,
а точный HEAD, команды проверки и пути доказательств.

Шаблон записи смены (копировать сюда, перезаписывая предыдущую; заполненный пример — «Где именно остановился»):

```text
# Передача смены — <дата>
Verified HEAD: <git rev-parse HEAD>   (git status --porcelain пуст; синхронно с origin)
Ветка / дерево: <branch> / <clean | dirty: что именно>

## Задача
ID из очереди: <H-… / N… / этап …>   Статус: DONE | PARTIAL | BLOCKED
Цель: <одно предложение>

## Проверено (команда → exit code → артефакт)
- <команда> → <rc> → <путь evidence>

## Не проверено (явно)
- <что осталось предположением; что НЕ запускалось>

## Не повторять
- <закрытое: F-… / C-… / коммит; не «чинить» снова>

## Изменённые файлы
- <пути>

## Решения / нужно владельцу
- decision-log: <строка>; требует «да»: <что>

## Точное следующее действие
1. <конкретный шаг с id задачи, не «продолжай улучшать»>

## Бюджет / правило остановки
- <лимит шагов/времени; когда остановиться и спросить>
```
