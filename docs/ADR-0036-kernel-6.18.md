# ADR-0036. Ядро для минимальной системы: Linux 6.18 LTS

**Статус:** принято по замеру 31.10.2026. Уточняет ADR-0033 (6.18 LTS) фактами.

## Контекст

Своя минимальная система — ядро + `hs-core` как PID 1 (см. `research/MINIMAL-OS-BOOT-2026-10-31.md`).
Нужно было выбрать ядро, а не унаследовать. Решающие требования:

1. **Landlock ABI ≥ 4** — иначе песочница не умеет ограничивать сеть.
2. **LTS** — система должна жить годами без переездов.
3. **Размер образа** — важен, но не любой ценой.
4. **Проверяемость**: ядро должно загружать наш бинарник в QEMU и сообщать свои свойства.

## Замер (все — реальная загрузка в QEMU, один и тот же initramfs)

| кандидат | ядро | Landlock ABI | размер | LSM стартует |
|---|---|---:|---:|---:|
| Alpine 3.20 | 6.6.134-0-lts | 3 | 10,5 МБ | 2,7 с |
| Alpine 3.21 | 6.12.114-0-lts | 6 | 12,7 МБ | 3,4 с |
| Alpine 3.22 | 6.12.114-0-lts | 6 | 13,1 МБ | 5,9 с |
| **Alpine latest-stable** | **6.18.58-0-lts** | **7** | **13,9 МБ** | 4,0 с |

Все четыре загрузили наш бинарник как PID 1 и напечатали одинаковый хеш печати. Различие — только
свойства ядра и размер.

Контрольные суммы выбранного ядра:
`14ac8b1b…` (SHA-256 целиком — в `core-rs/boot/`, в git не коммитится).

## Решение

**Ядро — Linux 6.18 LTS** (`6.18.58-0-lts`, образ Alpine latest-stable netboot).

Причины:

1. **Landlock ABI 7** — максимум из доступного: сеть, ioctl, ограничения scoped-сигналов. Это закрывает
   нашу дыру «песочница без сети» без самодельных механизмов.
2. **LTS** — соответствует ADR-0033; поддержка годами, без гонки за версиями.
3. **Цена +3,4 МБ** к 6.6 при образе 311 КБ — незначима: наша часть в 40 раз меньше ядра.
4. **Быстрее не значит лучше**: 6.6 стартует на 1,3 с раньше, но не даёт сети в песочнице; разница в
   загрузке не меняет ничего для харнесса.

## Следствия

1. `core-rs/build.ps1` по умолчанию берёт **6.18**, откат на 6.6 — явным флагом.
2. `hs-core` в режиме init печатает **версию ядра и Landlock ABI** — свойства ядра стали проверяемыми,
   а не предполагаемыми.
3. Гейт «ядро» (в планах): система не считается годной, если ABI < 4.
4. Ядро 6.6 остаётся как аварийный вариант: если 6.18 покажет дефект, откат — одна строка.

## Риски

- 6.18 моложе 6.12: меньше полевых данных. Лечение — аварийный откат и то, что наша часть не зависит от
  новых API, кроме Landlock.
- Ядро поставляется Alpine netboot: зависимость от их сборки. Для «своего всего» (D5) позже можно
  собрать своё ядро с нужным конфигом; сейчас цена не оправдана.
