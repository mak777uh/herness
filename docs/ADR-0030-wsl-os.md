# ADR-0030 — WSL: дистрибутив уже есть, ограничение — диск

Дата: 30.10.2026. Статус: принято по замеру. Заменяет обсуждение «какой дистрибутив выбрать».

## Что измерено (не предположено)

| факт | значение | чем измерено |
|---|---|---|
| WSL | версия 2, дистрибутив **Ubuntu 24.04.5 LTS** уже установлен | `wsl -l -v` |
| ядро | 6.6.114.1-microsoft-standard-WSL2 | `uname -r` |
| systemd | **работает** (PID 1 = systemd) | `ps -p 1 -o comm=` |
| glibc | **2.39** | `ldd --version` |
| python | 3.12.3 (есть) | `python3 --version` |
| git | 2.43.0 (есть) | `git --version` |
| нет | cargo, rustc, zstd, psql, node, docker, lean, lake | `command -v` |
| занято в дистрибутиве | `/usr` = 7.0 ГБ, диск WSL 4.1 ГБ (vhdx на C:) | `du`, размер файла |
| **свободно физически** | **C: 13.3 ГБ, G: 6.4 ГБ** | `Get-PSDrive` |

## Почему вопрос «какой дистрибутив» — не главный

Все кандидаты на нашем наборе задач почти не различаются:

| вариант | glibc | Lean/Rust | цена диска | вердикт |
|---|---|---|---|---|
| **Ubuntu 24.04 (есть)** | 2.39 | Rust — да, Lean — да | 0 (уже стоит) | **оставляем** |
| Debian 12 | 2.36 | да | +0.5–1 ГБ на установку | смысла нет: glibc старее, выигрыш копеечный |
| NixOS-WSL | 2.3x | да, воспроизводимо | +2–3 ГБ store и рост | отложить до свободного диска |
| Arch | свежий | да | +1 ГБ, rolling | не для воспроизводимости |
| Alpine | musl | **нет** | мало | исключён ранее: ломает Lean и forge |

Разница между Ubuntu и Debian на нашем наборе — 2.39 против 2.36 glibc и полгигабайта. Это не тот
выбор, ради которого стоит переставлять систему.

## Решение

1. **Остаёмся на Ubuntu 24.04.** Она уже стоит, systemd работает, glibc 2.39 подходит для Rust и Lean.
2. **Ничего не переставляем и не добавляем второй дистрибутив**: свободного места 13.3 ГБ, а один
   только Lean 4 с mathlib — это 5–8 ГБ.
3. **Внутри WSL ставим только то, что не влезает в бюджет** (см. ниже), и по одному.
4. **Lean остаётся на Windows** (там уже 6 ГБ тулчейнов) до изменения диска.

## Бюджет диска (объявлен заранее)

| что | оценка | ставим? |
|---|---|---|
| Rust (rustup + cargo) | 1.5–2 ГБ | да, первым |
| PostgreSQL 16 + клиент | 0.1–0.2 ГБ | да, для пилота |
| zstd | <0.01 ГБ | да |
| Lean 4 + mathlib | 5–8 ГБ | **нет** при 13 ГБ свободных |
| Docker | 1–2 ГБ + образы | нет до появления места |

Правило: перед установкой проверять `df -h /` и не начинать, если после установки останется < 5 ГБ.

## Как проверить, что решение верное

1. `wsl -d Ubuntu-24.04 -- bash -lc "df -h /; python3 -V; git --version"` — окружение живое.
2. После установки Rust: `cargo --version` и сборка одного крейта (проверка, что glibc хватает).
3. `ps -p 1 -o comm=` → `systemd` — значит Postgres можно держать службой, а не вручную.

## Когда пересматривается

- появилось ≥40 ГБ свободных → можно NixOS-WSL ради воспроизводимости окружения;
- понадобился Lean внутри Linux → сначала освободить место, потом ставить;
- понадобился Docker → оценить, влезает ли 1–2 ГБ плюс образы.

## Чего это решение не даёт

- **Воспроизводимости уровня ОС.** Ubuntu 24.04 с ручными установками — это «как получилось», а не
  «как зафиксировано». Nix дал бы пиннинг, но не влезает по диску.
- **Изоляции.** WSL — это не контейнер; он видит диск Windows через `/mnt/c`.
- **Проверки на других машинах.** Всё измерено на одной.

## Что осталось неизвестным

- Точные размеры Rust и Postgres в этом дистрибутиве — оценка, а не замер; проверим при установке.
- Влияние `/mnt/c` на скорость git-операций в WSL — не мерили. Если окажется медленно, работать
  придётся в нативном каталоге WSL, а не в `/mnt/c/111`.
