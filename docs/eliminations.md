# eliminations.md — что проверено и отброшено

Каждая строка: гипотеза → чем проверяли → вердикт → что бы её оживило.
Записи append-only: исправление — новая секция, а не переписанная история.

## E-0000. Форк установленного `app.asar`

- **Гипотеза:** единственный способ получить нужное поведение — форкнуть приложение.
- **Проверка:** `docs/architecture.md` DSH — cordis, «нет привилегированного ядра»; seam'ы
  `agent-loop`/`session`/`tools`/`llm` заменяются плагинами; `DSH_HOME` изолируется (проверено
  `hs doctor`).
- **Вердикт:** `refuted` для целей v1. Форк не нужен, пока требования закрываются плагинами.
- **Что оживит:** требование, которое нельзя выразить на seam'ах (например, замена формата
  сессии без потери совместимости) — тогда отдельный ADR.

## E-0001. Переписывание рантайма с нуля на Python

- **Гипотеза:** свой рантайм на Python проще и быстрее в разработке.
- **Проверка:** объём «скучной» части — `llm`-стриминг, схема сообщений, персистентность с
  версионированием (v0→v3 миграции), песочница, tool-схемы; в DSH это ~50 пакетов.
- **Вердикт:** `deferred` (не отброшено, но не в v1). Python берёт слой истины, не цикл.
- **Что оживит:** если плагинный слой DSH окажется неспособен обеспечить durable-результаты и
  супервизию — тогда свой цикл, но с переиспользованием `@deepseek-ai/dsh-llm`.

## E-0002. Лимит трафика как посылка (опровергнуто владельцем)

- **Что было придумано:** «сейчас мобильный интернет» → «значит расход ограничен» → режимы
  `mobile`/`full`, правила экономии, критерий K83.
- **Что сказал владелец:** тариф безлимитный, ограничений по расходу нет. Ограничение — только
  качество канала (задержка, обрывы).
- **Вердикт:** `refuted`. Посылка была выдумана, а не дана. Документ `NETWORK-MODE.md` удалён,
  K83 переведён в `опровергнуто`.
- **Урок:** незаданное условие — это `undefined`, а не допущение по умолчанию. Чем дальше строишь
  на выдуманной посылке, тем дороже её снятие: она становится контекстом.
- **Что оживит:** если тариф станет лимитированным — вернуться к режимам, но с замером, а не с
  догадкой.

## E-0003. Своё ядро ОС (ступень D5)

- **Гипотеза:** для оптимальности стоит писать ОС целиком, включая ядро.
- **Проверка:** лестница глубины (`docs/DEPTH.md`): D4 (своя ОС вокруг чужого ядра) даёт всё, кроме
  самого ядра; D5 добавляет драйверы, поддержку железа и годы работы, а выигрыша для наших задач
  (журнал, свидетельства, инструменты, сеть) не добавляет — ни одно из наших требований не упирается
  в ядро.
- **Вердикт:** `refuted` — решение владельца 30.10.2026: «D5 — драйверы и годы без видимого выигрыша».
- **Что оживит:** требование, которое ядро реально ограничивает (например, детерминизм на уровне
  планировщика, изоляция без контейнеров, свои сетевые гарантии) — и замер, показывающий, что на D4
  это недостижимо.

## E-0004. Bing как источник поиска для агента

- **Гипотеза:** `https://www.bing.com/search?q=<запрос>&setlang=en` даёт пригодную выдачу; для агента
  достаточно RSS-варианта (`&format=rss`).
- **Проверка (30.10.2026):** три запроса, ответ 200, по 10 элементов. Релевантность считалась по
  заголовкам и сниппетам элементов: «linux 6.18 lts eol» — 0 из 4 терминов, «python 3.13 release
  notes» — 1 из 4, «nixos 26.05 release» — 0 из 3. Вместо выдачи приходят ссылки на Microsoft,
  SharePoint и TradingView.
- **Вердикт:** `refuted` — технически работает, содержательно это заглушка для ботов. Статус 200 и
  десять элементов не значат «ответ на запрос».
- **Что оживит:** проверка с полноценной сессией/ключами (Brave, Tavily), собственный SearXNG или
  адресные API (GitHub, arxiv, endoflife.date) — они и работали в этой сессии.
- **Следствие в коде:** `core/search.py` возвращает `decoy`, если слова запроса отсутствуют в выдаче;
  `hs search` в этом случае завершается с кодом 1.

## E-0005. Бесплатный веб-поиск без ключа из этой сети

- **Гипотеза:** плагин `dsh-free-search` с бесплатными движками даёт рабочий поиск без ключей.
- **Проверка (30.10.2026):** перебор 43 экспортов движка напрямую в Node. DuckDuckGo (html/lite/
  videos) — 0 результатов (капча); Bing — 0–1 и заголовки не про запрос; публичные SearXNG — 429;
  Exa/Firecrawl/Jina/Keenable/AnySearch — `fetch failed` без ключа; Baidu/Aliyun/Doubao/Kimi/Claude/
  Gemini/DeepSeek — требуют ключа; GitHub с нашим токеном — 0.
- **Вердикт:** `refuted` для «без ключа и без своего инстанса». Сам плагин исправен: движки отвечают
  пустотой или лимитом, а не ошибкой плагина.
- **Что оживит:** ключ бесплатного тира (Exa/Tavily/Brave) или свой SearXNG.
