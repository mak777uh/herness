## Как перевести в творческий режим

**Creator Mode (пресет `cordis`)** — режим, где агент сам пишет и подключает плагины DSH.

**Что сделать:**

**1.** В DSH откройте настройки → **Agent preset** (или `/preset`).

**2.** Выберите **`cordis`** — это встроенный пресет Creator Mode.

**3.** Новый чат начнётся уже в творческом режиме.

**Через плагин `dsh-gamemode`:** команда `/gamemode 1` переключает на `cordis`.

**Это Public Preview.** Код выполняется **без глубокого аудита**. Изоляция экспериментальная.
