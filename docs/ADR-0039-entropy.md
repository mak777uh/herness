# ADR-0039. Источник энтропии в ядре: C + `HW_RANDOM_VIRTIO`

**Статус:** принято по замеру 31.10.2026. Дополняет ADR-0038 (конфиг C), не меняя остальных опций.

## Контекст

В конфиге C нет ни `CONFIG_HW_RANDOM`, ни `CONFIG_VIRTIO_RNG`, ни `CONFIG_RANDOM_TRUST_CPU`.
Проверка конфига, а не догадка:

```
CONFIG_RANDOM_TRUST_CPU — нет
CONFIG_HW_RANDOM — нет
CONFIG_HW_RANDOM_VIRTIO — нет
CONFIG_VIRTIO_RNG — нет
```

Это не косметика: Rust-овский `HashMap` берёт seed из `getrandom`, и первый же `HashMap` в цикле
может стать местом, где система «иногда думает сорок секунд».

## Замер

Проба добавлена в `hs-core` (режим init) и печатает механизмы, а не опции:

```
C  (без HW_RANDOM): 1 487 872 байт
способы: exec ok, pipe ok, fsync ok, часы ok, случайность нет (EAGAIN), epoll ok, eventfd ok, memfd ok

E  (C + HW_RANDOM_VIRTIO): 1 496 064 байт (+8 192)
способы: exec ok, pipe ok, fsync ok, часы ok, случайность ok, epoll ok, eventfd ok, memfd ok
```

Оба прогона — одно и то же устройство `-device virtio-rng-pci`, один initramfs, `-accel whpx`.

Цена: **+8 192 байта (0,55 %)**, время до init в пределах шума (0,71–1,05 с против 0,53–0,78 с).

## Решение

1. Собираем вариант **E** (`core-rs/build-kernel-rng.sh`, конфиг `kernel/config-6.18.60-rng`,
   образ `boot/vmlinuz-own-rng`).
2. `run.ps1` по умолчанию берёт `vmlinuz-own-rng` и добавляет `-device virtio-rng-pci`.
3. **`случайность ok` стало ожиданием прогона**: ядро без источника энтропии теперь роняет цикл
   проверки, а не проходит молча.

## Следствия

- `vmlinuz-own` (сборка C) остаётся в `boot/` как измеренная база для сравнения; замеры C-0127/0128
  остаются верными для той сборки.
- `CONFIG_RANDOM_TRUST_CPU` **не включён**: «доверять RDRAND всегда» — это политика, а не факт, и
  принимать её молча нельзя.

## Границы

- `EAGAIN` означает «пока нет энтропии», а не «нет никогда»: через секунды работы пул может
  заполниться сам. Утверждение точное: *на старте, до первого устройства, энтропии нет*.
- Мерили в QEMU с `virtio-rng-pci`; на голом железе источник другой (RDRAND, таймеры), и там
  поведение не проверялось.
- Включение драйвера — это ещё один драйвер в ядре (плюс к поверхности), цена в байтах измерена,
  цена в поверхности — нет.
