## Как раздавать

1. **Один промпт — пять моделей.** Модели не должны видеть ответы друг друга: иначе получим
   консенсус вместо независимых наблюдений.
2. **Разные модели — разные сильные стороны.** Одна пусть ищет код и спеки, другая — статьи и
   обзоры, третья — практику эксплуатации. Но промпт один.
3. **Проси ровно формат из промпта.** Таблицы сравнимы, эссе — нет.
4. **Никаких «а что ты думаешь про мой проект»** — только вопросы про внешний мир.

## Куда складывать

```
research/answers/P1/<модель>.md
research/answers/P2/<модель>.md
...
```

Имя модели — как есть (`gpt`, `claude`, `gemini`, `qwen`, `deepseek`), без версий в имени файла:
версию пиши внутри файла первой строкой.

## Как из этого делать вывод

Протокол в [QUESTIONS.md, раздел C](../QUESTIONS.md). Коротко:

- каждое утверждение → строка с URL и датой;
- нет источника → `judgment`, в вывод не идёт;
- модели разошлись → открытый вопрос, **не усредняем**;
- совпало у ≥3 и подтверждено источником → в дайджест `research/DIGEST-<тема>.md`;
- в конце дайджеста — «что эти ответы не решают».
