# P9 — Маршрутизация задач и инструментов (не моделей)

## Контекст

Я строю персональный агентский харнесс для одного владельца. Запрос человека раскладывается на
фрагменты; каждому фрагменту назначается **тип задачи**, а типу — **уровень вмешательства**:

- **L0** — ничего: только ответ модели;
- **L1** — инструменты: оболочка, файлы, сеть;
- **L2** — инструменты плюс протокол: журнал, артефакты, отчёт, явные границы;
- **L3** — плюс сервер, блокировки, мультиагентность.

Нужно не «какую модель выбрать», а **как решать, какой объём инструментов и строгости нужен задаче**.

## Правила ответа

1. Не выдумывай; нет данных — `нет данных`.
2. Каждое утверждение — со ссылкой (URL) и датой.
3. Для каждого пункта укажи **тип свидетельства**: `эксперимент` / `бенчмарк` / `реализация` /
   `обзор` / `мнение`.
4. Если работа смешивает «маршрутизацию моделей» и «маршрутизацию задач» — скажи это прямо.
5. В конце — раздел **«Чего я не смог проверить»**.
