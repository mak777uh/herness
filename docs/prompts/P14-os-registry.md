# P14 — Реестр ОС: установить факты, дополнить список

Скопируй блок и отдай модели с веб-поиском. Задача — установить факты и дополнить наш список ОС,
а не советовать «что выбрать».

```text
Задача: построить реестр операционных систем для одного владельца и долгоживущего агентского
харнесса. Нужны проверяемые факты, дополнение нашего списка и явные пробелы. Выбор мы сделаем сами.

КРИТЕРИИ (по ним и заполняй; не добавляй своих без пометки):

5. Если твои данные расходятся с нашими (см. выше) — покажи расхождение и ссылку, а не молча замени.
```

## Зачем именно так

- **Наш список — стартовая точка, а не граница.** Модель обязана либо подтвердить его, либо добавить
  ОС с обоснованием: так мы перестаём выбирать из того, что вспомнили (ошибка F-0013).
- **Критерии пронумерованы** — потом можно сверять ответы разных моделей по клеткам R1…R10.
- **Форма фиксирована** — ответы складываются в одну таблицу без ручного переписывания.
- **Наши факты даны явно** — чтобы модель не тратила ответ на их «открытие» и чтобы расхождение
  с ними было видно.
